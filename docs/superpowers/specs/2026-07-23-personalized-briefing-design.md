# 个性化简报按需生成 — 设计文档

日期：2026-07-23
状态：已确认

---

## 1. 目标

让用户输入自己感兴趣的新闻种类，系统按需生成专属简报。支持两种输入方式：
- **自然语言描述**：如"我对AI编程工具和自动驾驶感兴趣"
- **标签快速点选**：从系统标签目录中选择

## 2. 架构总览

在现有通用简报流程之外，新增一条**按需生成**路径：

```
用户输入 → 敏感词过滤 → 新闻相关性判断 → LLM兴趣解析 → 标签映射 → 轻量流水线 → 存储+展示
```

## 3. 输入校验层（同步，< 200ms）

在进入 LLM 解析+流水线之前，先过两道闸门：

### 3.1 敏感词过滤
- 敏感词库存储在配置/数据库中，支持动态更新
- 命中后**不透露具体敏感词**，统一返回："请输入有效的新闻兴趣"
- 匹配策略：精确匹配 + 拼音变体 + 常见绕过（空格、符号分隔）

### 3.2 新闻相关性判断
- 轻量 LLM 分类（~50 tokens prompt）："这个输入是在描述对某类新闻/资讯的兴趣吗？"
- 非新闻输入举例：天气、写代码、做作业、讲笑话、闲聊
- 被拒绝时引导用户："请输入你感兴趣的新闻领域，比如'AI 编程工具'、'自动驾驶'、'科技公司动态'"

## 4. 专属简报流水线（轻量版，预计 30-45 秒）

相比通用简报跳过多项 LLM 调用，大幅提速：

| 步骤 | 通用简报 | 专属简报 | 说明 |
|------|---------|---------|------|
| AI 评分 | ✅ 逐条 LLM | ❌ 跳过 | 复用已缓存的 ai_score |
| 时效性门禁 | ✅ | ✅ 保留 | 36h→48h→72h 三级回退 |
| URL 去重 | ✅ | ✅ 保留 | 同批次内精确去重 |
| 跨天去重 | ✅ | ❌ 跳过 | 专属简报独立去重池 |
| 语义去重 | ✅ | ✅ 保留 | AI 语义相似度去重 |
| 标签预过滤 | ❌ | ✅ | 按用户兴趣标签过滤 |
| AI 辩论 | ✅ | ❌ 跳过 | 三 Agent 辩论，耗时大户 |
| 背景补充 | ✅ | ❌ 跳过 | LLM 补全背景信息 |
| 翻译 | ✅ | ✅ 保留 | 英文内容翻译为中文 |
| AI 摘要 | ✅ | ✅ 保留 | 核心步骤，不可跳过 |
| 配图匹配 | ✅ | ✅ 保留 | Unsplash/图片搜索 |

**预计加速：** 通用简报 90-120 秒 → 专属简报 **30-45 秒**

### 4.1 数据源
- 按需生成时，自动查找最新的 `batch_id`（module-a 当天已抓取的 raw_items）
- 如果没有当天数据，先触发 module-a 做一次快速抓取，再跑流水线

## 5. LLM 兴趣解析

用户的自然语言输入经 DeepSeek 轻量解析：

```
输入: "我想看AI编程工具和自动驾驶相关的内容"
输出: { tags: ["AI编程", "自动驾驶", "工具"], keywords: ["编程", "Copilot", "IDE"] }
```

- `tags` 传入流水线的 `filter_tags`，精准过滤
- `keywords` 辅助在摘要结果中提升匹配条目权重
- 与用户手动点选的标签做并集

## 6. 去重策略

专属简报与通用简报**完全独立**：
- 专属简报中出现的新闻，不影响通用简报
- 跨用户的专属简报之间也不去重
- 专属简报仅在其自身批次内做 URL 去重和语义去重

## 7. 前端改动

### 7.1 首页（index）
- Tab 栏下方新增可折叠兴趣输入面板
  - 折叠态：一行提示「定制你的专属简报 ▾」
  - 展开态：文本输入框 + 常用标签芯片 + "生成我的简报"按钮
- 生成中：显示加载动画「正在为你精选新闻…」+ 轮询状态
- 生成完成：面板收起，展示专属简报，顶部标记「🔍 按你的兴趣生成：AI编程、自动驾驶」
- 不输入时默认显示通用简报，保持现有体验

## 8. 后端 API

### 8.1 `POST /api/briefings/generate`
触发个性化生成：
- 入参：`{ openid, interest_text, tags: ["LLM"], type: "morning" }`
- 返回：`{ task_id, status: "processing" }`
- 内部流程：
  1. 敏感词过滤
  2. 新闻相关性判断
  3. LLM 兴趣解析 → 标签映射
  4. 查找最新 batch_id
  5. 启动异步流水线任务
  6. 返回 task_id

### 8.2 `GET /api/briefings/generate/{task_id}`
轮询生成状态：
- 返回：`{ status: "processing" | "completed" | "failed", briefing_id, error }`

### 8.3 `GET /api/briefings/my`
获取用户专属简报历史：
- 入参：`openid, page, size`
- 返回分页列表

## 9. 数据模型变更

`briefings` 表新增字段：
- `requested_by` VARCHAR — 用户 openid（NULL = 通用简报）
- `interest_text` TEXT — 用户原始输入
- `interest_tags` JSONB — 解析/选择后的标签
- `is_personalized` BOOLEAN DEFAULT false

## 10. 并发与容错

- 同一用户最多 1 个进行中的生成任务，新提交取消旧任务
- 生成超时（> 3 分钟）→ 标记 failed，提示用户重试
- 最新 batch 无匹配标签的新闻 → 返回"该领域暂无今日新闻"
- 未登录状态 → 使用设备标识，体验不受影响
- 前端轮询间隔：2 秒，最多轮询 90 次（3 分钟）

## 11. 差异对比

| 维度 | 通用简报 | 专属简报 |
|------|---------|---------|
| 触发方式 | 定时任务 | 用户手动输入 |
| AI 评分 | LLM 逐条打分 | 复用缓存分数 |
| AI 辩论 | 高分条目三 Agent | 跳过 |
| 背景补充 | LLM 补充 | 跳过 |
| 生成耗时 | 90-120s | 30-45s |
| 去重范围 | 跨天全局 | 批次内独立 |
| 存储标记 | is_personalized=false | is_personalized=true |
